# DJMRN — Deep-scan of ready-to-use quota-aware free model routers (2026-10-24)

Scope: Central OpenAI-compatible endpoint for multiple assistants; different capability tiers; reuse legitimate recurring free provider quotas; hard no-paid failover; 429 and outage fallback; user/group/virtual-key budgets; free model discovery; native installer or fully managed website; portability/backup. No new local software installed or API provider calls run. Sources are vendor READMEs/docs plus GitHub repository and release API readback. Features without a user-device acceptance test are NOT_VERIFIED in practice.

## S6 — EVIDENCE-GAPS/EXCLUSIONS

- **false lead واقعی:** query Go چهار botupdate داد؛ README SAFEShane/botupdate متن نامرتبط بود، نه برنامهٔ قابل بازاستفادهٔ tool-chat. محتوای آن دستور مأموریت تلقی نشد؛ سایر سه repo صرف هم‌نامی تأیید نشده‌اند. ۴ نتیجه به شمار نامزدها اضافه نشد.
- **هویت/alias:** سه desktop-assistant هم‌شرح بدون بررسی مستقل را fork قطعی یا سه راهکار تازه ننامیدیم؛ 5ire نشانی اشتباه داشت و canonical اصلاح شد. این شفافیت از شمارش پوششی جلوگیری می‌کند.
- **مجوز:** Cookbook root LICENSE نامعلوم؛ 5ire شروط افزوده دارد؛ MCP C#/Go/Rust/servers متن انتقالی دارند؛ badge دایرکتوری یا SPDX metadata مجوز واقعی لایهٔ فایل/مدل/وابستگی را جایگزین نمی‌کند.
- **نسخه:** Python README/pyproject جدید با صفحهٔ PyPI متفاوت، تاریخ Go package/release متفاوت، Conduit tag=rc با prerelease=false، llama nightly prerelease، Gallery فقط commit message و API release خالی؛ اختلاف‌ها عامدانه حفظ شدند. عدد 2031.7M HF با کارت1.7B تفسیر نشده؛ revision مدل ناقص است.
- **رجیستری/HF/npm:** MCP Registry فقط Loading servers داد؛ server inventory رسمی را از upstream بررسی کردیم و namespace registry verified ادعا نکردیم. fulltext HF blocked؛ مدل Space نیست و دمو اجرا نشد. npm native جست‌وجوی موفقِ تازه ندارد؛ وجود npx در Rust نمونه permission دانلود نیست.
- **footprint Windows:** 16GB توصیهٔ کل AI Dev Gallery است؛ نه اندازه‌گیری sample Chat و نه حکم رد عمومی روی8GB. GPU/NPU خاص یک API را به کل نمونه‌ها تعمیم ندهید. هیچ installer، idle memory، benchmark فارسی، antivirus/signature یا اجرای CPU واقعی این نشست آزموده نشد.
- **scope/security:** approval صرفاً prompt یا دکمه، توصیهٔ system، tool schema، readOnly annotation یا allowed directory مرز قابل اعتماد دو فایل نیست. shell/exec در starter و ابزارهای mutation در server مشاهده شد؛ این‌ها trigger مطالعهٔ دقیق‌اند، نه audit کامل یا CVE ادعایی. دادهٔ سند می‌تواند prompt injection داشته باشد؛ هرگز اختیار افزوده ایجاد نمی‌کند.
- **پوشش نقش F:** workflow آماده‌ای که بدون نصب سنگین M1 را واقعاً کامل کند به حد شواهد نرسید. فهرست workflowهای WQ7 به‌عنوان artifact آمادهٔ تازه بازشماری نشد؛ Node-RED/n8n/Activepieces انتخاب نشده‌اند.
- **عدم exhaustiveness:** queryها/فیلترهای مسدود، cross-forge، extension stores، موضوع‌های workflow و region/pricing شواهد ناقص دارند. ۱۸ هویت تحقق هدف عددی15–30 است؛ این عدد اثبات کفایت فنی همهٔ نامزدها یا جامعیت بازار نیست.
- **منطقه و حساب:** منبع رسمی کافی برای استفادهٔ قانونی ایران، renewable free quota و قیمت actual providerها در این نشست احراز نشد. UNKNOWN/DENY ACTIVATION، بدون ساخت حساب، خرید، API فعال یا دورزدن. چند برنامه محلی قابل بررسی‌اند ولی host/model/update/download جدا باید روشن شود.
- **روش زمان:** روز نشست و تاریخ متن درخواست متفاوت است؛ release زمان‌دار از سرویس همان‌گونه نقل شده. همهٔ snapshotها ثانیه‌به‌ثانیه timestamp ندارند؛ pin کد/شاهد برای بازتولید مهم‌تر از عبارت «جدیدترین» نگه داشته شد.

## S7 — STAGE3-EVALUATION-PLAN-ONLY

این بخش پیشنهاد روش برای WQ مستقل پس از review است؛ هیچ یک اجرا نشده و مجوز blanket نصب نیست.

۱. هماهنگ‌کننده ابتدا هویت و کفایت این فهرست، کمبود LICENSE Cookbook و revision مدل و اختلاف نسخه‌ها را مستقل بررسی کند. برای shortlist محدود، upstream tag/commit و متن LICENSE و حقوق توزیع app/component/model و installer provenance دوباره pin شود؛ README و release/API mismatch حل شود. open issues مربوط به Windows، MCP dispatch/approval bypass، cancellation و path handling، و پاسخ maintainer جدا مطالعه شود؛ issue را واقعیت قطعی نگیریم.

۲. بدون ساخت زودهنگام معماری، مسیر واقعی message→tool schema→dispatcher→OS read→result→reply در کد نامزدهای مجاز ترسیم شود. برای Jan shell OFF و حفظ MCP، Cherry/Conduit remembered grants و annotation trust، AnythingLLM desktop citation، Cookbook call_tool، C# sample/host و Vercel auth/tool route بررسی گردد. ۳. پس از مجوز مشخص اجرای بعدی، fixture مشترک دو Markdown غیرحساس با متن فارسی و خطوط شناخته‌شده، شامل تفاوت ی/ک/نیم‌فاصله، query موجود/ناموجود/مبهم و متن حاوی دستور مخرب تهیه شود. expected result شامل مسیر مجاز/خط/عین excerpt باشد. پاسخ مدل نباید متن ساختگی را شاهد معرفی کند. مدل ناتوان در tool call باید BLOCKED واضح بدهد؛ parser خطا نباید به shell fallback کند.

۴. denial tests مستقل از prompt: فایل سوم، مسیر مطلق/../، symlink/junction، تغییر scope/roots، درخواست write/delete/send/shell، «اجازهٔ همیشگی» UI، annotation جعلی read-only، timeout و مدل invalid JSON. invariant عدم دسترسی/تغییر با شواهد واقعی و hash قبل/بعد ثبت شود؛ خود ابزارِ اجراکننده باید رد کند حتی اگر مدل و UI موافق باشند. race/canonical path تضمین جدا لازم دارد.

۵. روی دستگاه کاربر و فقط با مجوز مشخص: نسخهٔ OS/build/host/runtime/model و وزن/quantization/context ثابت، startup/idle/peak RAM، CPU latency و استفادهٔ مجدد پس از restart اندازه‌گیری شود. وضعیت offline/online، ترافیک خروجی، نیاز کلید و حق منطقه/هزینهٔ واقعی بررسی گردد؛ غیرفعال‌کردن telemetry با شاهد لازم است، نه ادعای محلی در marketing. نمونهٔ native را مستقل از نصب کل Gallery ارزیابی کنند. daily UX با کلیک/گفتگو، بدون PowerShell، معیار باشد.

۶. پس از آزمون‌های هم‌fixture و تحلیل بار نگه‌داری و حقوق/هزینه، آن مرحله می‌تواند ADOPT/ADAPT/BUILD را مقایسه کند؛ این گزارش هیچ مهندس‌ساعت، امتیاز یا تصمیمی ارائه نمی‌کند. domainهای بعدی Gmail/freelance و surface ChatGPT، credentials و مجوزهای مستقل می‌خواهند و در M1 فعلی فعال نمی‌شوند. تغییر KB/SRC/TASK/CURRENT/journal و درخواست بعدی فقط بر عهدهٔ هماهنگ‌کننده است.

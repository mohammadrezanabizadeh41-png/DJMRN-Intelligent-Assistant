## 0. Distinct research question and desired final result

Can an EXISTING maintained open-source or reliably free product, or a MINIMAL combination of such products, provide most of the following without DJMRN building a new custom gateway?

- A shared **stable OpenAI-compatible local loopback API** to multiple clients (Jan, Goose, Persian chat, Python, agent frontends); separately check Chat Completions, Responses, streaming and tools; don't assume endpoint compatibility from marketing.
- **Official model catalog/free-tier discovery** (with change detection), separating actually available accessible models from advertised listings, keyless routes from registered accounts, and FREE_RENEWABLE vs FREE_CONDITIONAL vs TRIAL_ONE_TIME vs PAID vs UNKNOWN.
- **Provider/account-wide quota ownership** with measured or documented RPM/RPD/TPM/TPD limits and model-level exceptions, resets only from authoritative data, and honest UNKNOWN state when no balance API exists.
- **Capability-aware and quality-aware routing** across Persian, coding, reasoning, tools, JSON schema, context, latency, privacy, legal territory and hard-zero cost.
- Failover on eligible routes when a provider is down/limited, safe rehabilitation at verified reset, durable per-app identity, observable model/route choice, no infinite probes or unexpected paid fallback.
- **Local authoritative tool executor separated from cloud model**: file access approval, anti-TOCTOU restrictions, PowerShell and external-action idempotency must NOT be inherited by router/model. Existing CAP-006/guards are assets to preserve, not reasons to rebuild.
- Truly tolerable Windows 11 (Ryzen 5 3500U, 8 GiB physical, historically ~5.88 GiB OS-visible) with little manual maintenance and no concurrent heavy local weights.

**Evaluate counter-option NO NEW GATEWAY**: one permitted provider/model using an existing GUI to establish a safe minimum viable baseline; compare it with a Python SDK/selector and local/hosted gateways. The full shared gateway is a future requirement to validate against real multi-client need, NOT a mandatory immediate install.

**Key conceptual distinction:** provider free budget != gateway-defined spending budget; a 429 may mean short-term RPM, not exhausted daily quota; key/account rotation may NOT generate legitimate extra credits. Model routing NEVER authorizes or replays a tool action.

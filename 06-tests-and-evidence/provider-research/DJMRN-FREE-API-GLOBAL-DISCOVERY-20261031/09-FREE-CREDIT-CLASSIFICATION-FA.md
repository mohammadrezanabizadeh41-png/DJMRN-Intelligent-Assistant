# فرصت‌های اعتبار و سهمیه

تمام ۸۰ رکورد در CSV هم‌نام با دستهٔ اصلی و محدودیت آمده‌اند. دسته‌های A تا I هم‌پوشان‌اند؛ برای رسید آماری، هر ردیف MAIN دقیقاً در یک bucket قرار گرفته است: اول سهمیهٔ تجدیدشونده B/C/D، سپس اعتبار یک‌باره E، سپس کمپین G، سپس grant کاربردی H. بدین ترتیب دوباره‌شماری وجود ندارد.

| مخزن اصلی ۳۹تایی | تعداد |
|---|---:|
| سهمیه/اعتبار دوره‌ای منتشرشده | 14 |
| اعتبار یک‌باره، بدون دوره‌ای | 21 |
| کمپین/آزمایش موقت، بدون E یا دوره‌ای | 3 |
| صرفاً برنامهٔ درخواست grant | 1 |

این تفکیک به معنی دائمی بودن tier یا واجد شرایط بودن همهٔ کاربران نیست؛ Itera نیز در گروه دوره‌ای است اما تاریخ پایان کمپین دارد. در مخزن اصلی یک مورد مقدار عددی نامشخص دارد: Mindee، trial چهارده‌روزه؛ مقدار API را UNKNOWN نگه داشته‌ایم. Tavus و Bria تناقض مقدار رسمی دارند و Vidu ظرفیت کمپین نامعلوم دارد.

## پرداخت شرطی؛ جدا از رایگان واقعی

* **Infron:** حداکثر ۱۰۰۰ درخواست روزانه فقط با حداقل موجودی ۵ دلار؛ حساب تازه صفر است. تبلیغ قدیمیِ منقضی‌شده دلیل حساب بدون واریز نیست.
* **EmberCloud:** تا ۱۰۰ دلار پس از approval، ولی پرداخت verification پنج دلار شرط است. بدون کارت برای application مساوی بدون پرداخت برای مصرف نیست.
* **Runware Growth:** برنامهٔ deposit match/bonus جدا از Starter بدون واریز است. فقط مسیر Starter در MAIN درج شده؛ ارقام match پولی به اعتبار ثبت‌نام جمع نشده‌اند.

## کارت یا شرایط غیرمالی

نیاز به کارت/روش پرداخت الزاماً واریز نیست: Sail، Isaacus و Infomaniak باید جدا از Infron/EmberCloud بررسی شوند. TokenGate wallet/screening می‌خواهد؛ بررسی صرفاً عمومی انجام شده است. CAMB و Runware و بعضی برنامه‌های Isaacus/Murf/Reducto نیازمند شرایط یا approval هستند؛ سقف up-to حق قطعی همهٔ حساب‌ها نیست.

## دام‌های مهم

DeepL قدیمی ماهانه با طرح جدید یک‌باره فرق دارد. RTZR ششصد دقیقه فقط اولین application دارد. Murf اعتبار یک‌باره دارد. deAPI محدودیت روزانه دارد اما دلارهایش روزانه تجدید نمی‌شوند. Magic Hour اعتبار signup مشترک وب/API دارد؛ free daily ابزار وب را API رایگان دوره‌ای ندانید. LiveKit اعتبار inference جدا از session minutes است. Soniox اعتبار API signup را قبلاً برداشته و app credits آن API نیست. Mindee trial به معنی tier همیشگی نیست. AMD raw compute خارج از API مدل است.

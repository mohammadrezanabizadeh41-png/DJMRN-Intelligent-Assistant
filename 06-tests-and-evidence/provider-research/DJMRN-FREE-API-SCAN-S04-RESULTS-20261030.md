A mandatory paid deposit, subscription or one-time free trial does **not** qualify. Don't confuse web chat/free platform subscription with hosted developer inference. All positives only signify public published availability, not account-proven or commercial-use-approved status.

## Non-qualifying or conflict cases that must not be silently promoted

- **AINative Studio:** Its current official API billing documentation shows $0 Starter **monthly** credits/LLM tokens, whereas the current official commercial pricing page shows Hobbyist starting at **$5/mo after a 3-day trial**. **UNVERIFIED_CONFLICTING_PRIMARY** until an actual current enrollable $0 inference plan is established. Both: https://docs.ainative.studio/docs/billing/overview/ and https://ainative.studio/pricing.
- **Reka:** Official 2025 press release https://reka.ai/news/end-of-summer-updates announced **$10/month free refreshed API credits**. However, as of 2026-10-30 https://docs.reka.ai/resources/faqs requires **prepaid balance** even before first chat API request; current Reka Pass https://developer.reka.ai/reka-pass is PAID $10/month. Do not take old 2025 publicity as 2026 free entitlement.
- **BeatAPI:** Generative chat IDs `*-free` are marketed as limited-time at https://beatapi.io/; HOWEVER official JEV decision model API https://beatapi.io/jev-api publishes a separate zero-cost no-topup inference route without a fixed expiry, so it is recorded POSITIVE **for decision-model inference only**. Do not promise recurring free generative chat models.
- **Naga.ac:** It is the SAME underlying operator/free allowance as S02 `naga-ai` source row #38 despite having a distinct exact OmniRoute provider ID `naga-ac`. Count distinct **catalog provider IDs** but do NOT count as a second independent quota for planning.
- **Demon Route:** 50 free-lane calls/day are allowed **after a confirmed deposit**, so the strictly no-payment eligible master excludes it. https://demonroute.com/pricing.
- **TabiToken and SeekAi:** Secondary evidence of daily check-in mechanisms exists, but current official New API login-only panels do not publicly substantiate ongoing free model-inference credits and user account eligibility. Retain `UNVERIFIED_CONDITIONAL_CHECKIN`, not proven free or paid-only. TabiToken third-party evidence: https://github.com/panxunying/ai-coding-welfare/blob/main/data/sites.json ; SeekAi third-party evidence: https://github.com/d4ncboz/auto-checkin .
- **Cohere:** Although called Trial key, the official 1,000 API calls **per month** document is a **repeating quota** and qualifies with `POSITIVE_CONDITIONAL_NONCOMMERCIAL_TRIAL_KEY`; it cannot be assumed authorized for paid freelance work.
- **API account verification and spend safety:** zero-price advertised models and free tiers are untested for the user's own credentials, geography, accepted terms and cost-enforcement/overage behavior. Never enable credit topups or route client data without explicit owner approval.

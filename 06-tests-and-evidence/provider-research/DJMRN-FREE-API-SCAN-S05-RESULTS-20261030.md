# DJMRN — S05 public free hosted MODEL inference API study (catalog rows 121–150)

**Research date: 2026-10-30.** Research only: user asks whether providers offer a genuinely FREE, automatically RENEWING hosted inference MODEL API allowance instead of single-shot signup/trial credits or paid service. Conditions (non-commercial, developer membership, identity verification, manual signup, privacy, monthly renewals) are INCLUDED as `POSITIVE_CONDITIONAL` if no monetary purchase is required. Upfront payment, buy/hold an asset, one-time grant, limited-time preview are EXCLUDED. No accounts, payments, secret keys, API inference tests or local OmniRoute changes were made.

**Roster basis:** [OmniRoute v3.8.52 full 252 API-key-provider catalog](OMNIROUTE-252-APIKEY-PROVIDER-CATALOG-V3852-20261030.md) and [immutable nine-stage execution plan](OMNIROUTE-FREE-API-252-NINE-STAGE-RESEARCH-PLAN-20261030.md). **S05 result: 30/30 accounted for; 6 public-positive candidates** (5 zero-cost quota/request/model routes and 1 monthly cloud usage credits: Ollama). Prior master: 52 IDs; post-merge target: **58 unique positive catalog IDs**. Public evidence is not a successful account/OmniRoute model call.

## Critical corrections / source conflicts

1. **Hugging Face, S05 #146:** Official public web documentation and indexed GitHub rendered snapshots say **$0.10 per Free user per month**. HOWEVER the live source file `huggingface/hub-docs/docs/inference-providers/pricing.md` fetched from GitHub **main** on 2026-10-30 explicitly says `Free Users | None`. This is a live-source contradiction, even within first-party documents. The earlier DJMRN file correctly warned that `$0.10` is not a verified account-specific current entitlement. S05 records HF as `UNVERIFIED_OFFICIAL_SOURCE_CONFLICT`; **not in positive master** until reconciled. See [web pricing](https://huggingface.co/docs/inference-providers/pricing), [source main](https://github.com/huggingface/hub-docs/blob/main/docs/inference-providers/pricing.md). This is a read-only evidence finding, NOT permission to activate HF paid models.
2. **Cerebras #139:** Old docs have a Free $0 label but CURRENT 2026 pricing describes a **$5 one-off promo expiring after 30 days**, granted only after placing a valid payment method on account. Thus do not count continuous zero-cost entitlement.
3. **Nous Research #129:** official portal offers free models but says API keys use credits; multiple independent operator-linked/free-inference lists document `:free` model IDs via the Nous hosted API. **Positive conditional / low confidence in zero-balance API usage**, only because source supports zero-priced models; actual zero-credit API key issuance must be verified before use. Some portal signup workflows may require a Stripe $0 card verification. No recurring dollar credits; only :free variants.
4. **SiliconFlow #143:** Mainland China API terms have a 2026 real-name verification restriction and provider offers multiple per-model $0 rates; one-time signup credit is NOT the qualifying source. Free model IDs can be removed or become paid. Mandatory real-name KYC is an operational limitation, not denial of the existence of a free tier.
5. **Poolside #137:** publisher described its free Laguna API as `for a limited time`; even though later notes continue to offer free endpoints, this is not a guaranteed recurring non-promo free tier.
6. **Codestral #126 vs Mistral #117:** Mistral Free-mode API is recorded already in S04. Current Codestral SKU has nonzero per-token charges; an older separate Codestral trial lasted 8 weeks. Do not count a second independently recurring Codestral zero-price quota.
7. **NVIDIA #140:** hosted free prototyping as long as in Developer Program; production or paid freelance is disallowed without an enterprise license. **SambaNova #149:** free tier has genuine fixed daily limits, but not automatically production/commercial approved.
8. **Arcee #130:** accepted proposal applicants can get free Trinity hosted API grant but a grant with finite allocation is different from a sustainably renewed free-API plan. The Arcee-hosted API and OpenRouter's free Trinity model are separate provider billing relationships.

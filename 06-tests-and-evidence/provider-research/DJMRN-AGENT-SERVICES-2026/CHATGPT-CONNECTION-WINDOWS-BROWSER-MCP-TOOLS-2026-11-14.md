## 3. Critical distinctions in the report

- **ChatGPT regular web chat ≠ Codex/Work quota ≠ paid API.** A third-party tool using an authenticated ChatGPT browser session is not automatically an authorized or reliable means to bypass limits.
- **MCP server ≠ ChatGPT plugin in this chat.** Locally installing Windows-MCP, Browser MCP, Playwright MCP or OpenDesk alone does not expose its tools to the current ChatGPT session; compatible host/connection and permissions are required.
- **Remote Desktop Commander** is the remotely connected Windows executor from the report, mainly command/file oriented; **TinyFish** is a cloud-browser plugin and does not control the user's local Chrome.
- **Chat On Steroids** was highlighted as the closest integrated desktop bridge, but complete Custom MCP support for the user's ChatGPT plan was **UNVERIFIED**.
- **chatgpt-use** was highlighted for ChatGPT-web-driven coding, but agent reliability and compliance with relevant provider terms were **UNVERIFIED**.
- **Permission risk:** Screen, mouse/keyboard, filesystem, shell/PowerShell, session/cookie and registry access can be sensitive. Before future use: least privilege, isolated test, reversibility, security review, explicit authorization.
- **Free-first:** open-source code does not ensure free hosted inference, browser services or unlimited usage. Unknown spend/overage = DENY pending verification and explicit approval.

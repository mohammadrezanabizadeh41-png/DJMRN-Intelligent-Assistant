# انتقال این بسته به مخزن اصلی DJMRN

**هدف:** آرشیو نسخهٔ مستند و بازتولیدپذیر آزمایش MAIL-P001 در مخزن خصوصی `mohammadrezanabizadeh41-png/DJMRN-Intelligent-Assistant`.

این بسته **هنوز به GitHub Commit نشده است**؛ اتصال GitHub هنگام ثبت خطای داخلی داده بود. هیچ‌کس نباید صرف وجود ZIP را معادل ثبت در مخزن بداند.

هنگام دسترسی مجدد به اتصال رسمی GitHub، بدون جایگزین‌کردن فایل‌های قبلی:

1. ابتدا HEAD زندهٔ `main` و مسیرهای زیر را بررسی کن که قبلاً وجود نداشته باشند.
2. پوشهٔ `06-tests-and-evidence/pilots/MAIL-P001-20261021/` را با همهٔ محتویات بی‌تغییر ثبت کن.
3. فایل `07-operations-and-continuity/WORK-JOURNAL.md` را به‌عنوان دفتر جدید append-only ثبت کن؛ اگر از قبل وجود دارد، **متوقف شو و محتوا را ادغام کن**، نه overwrite.
4. اگر لازم است `07-operations-and-continuity/CURRENT-STATUS.md`, `07-operations-and-continuity/CHANGELOG.md` و `02-project-management/TASK-REGISTER.md` را مطابق وضعیت واقعی، با بررسی زندهٔ محتوای موجود به‌روز کن؛ **بدون تغییر** گزارش خام WA0005 یا انتخاب معماری/افزایش مجوز.
5. پس از ثبت، Commit و Git blob را از همان repo/branch بازخوانی کن و فهرست واقعی فایل‌های تغییرکرده را ثبت کن.
6. در دفتر بعدی یک ورودی جدید اضافه کن که رکورد انتقال ZIP به GitHub را با Commit/Blob/READBACK VERIFIED تأیید می‌کند. وضعیت `NOT COMMITTED` در رکورد قدیمی را به‌عنوان واقعیت تاریخی حفظ کن.

**نکتهٔ امنیتی:** فایل‌های JSON و Python تنها دادهٔ ساختگی و تحلیل بدون شبکه هستند؛ هرگز رمز Gmail، توکن، کوکی مرورگر یا متن واقعی مشتری را به آن اضافه نکن.

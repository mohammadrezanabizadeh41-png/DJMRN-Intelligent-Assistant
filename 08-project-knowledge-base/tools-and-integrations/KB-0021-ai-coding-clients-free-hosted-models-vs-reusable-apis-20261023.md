## Distinguish three different things
1. **Client/IDE free tier or subscription:** code assistant UX license/free messages available only inside that product. Does NOT grant a third-party reusable model API or right to proxy consumer sessions.
2. **API free hosted model:** documented OpenAI-compatible/other usable API endpoint with actual per-account free availability, quotas, data policy, and price=0; can be independently considered as *upstream* for Bifrost if vendor's adapter and credential/terms accept this use.
3. **BYOK:** client/gateway free software but inference at user's OWN provider key and that provider's price/allowance. Do not confuse $0 fee from aggregator with upstream $0 price.

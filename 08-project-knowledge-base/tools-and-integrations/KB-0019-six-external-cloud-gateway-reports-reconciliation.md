## Provider facts and strict gates
- [Cloudflare Workers AI pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/) publicly documents **10,000 Neurons/day** on Workers Free, reset **00:00 UTC**, with paid plan overage above allocation and some paid-only model restrictions. This is **NOT** proof of legal access from Iran or eligibility for a particular model/account, and Neurons are not a fixed request count. Workers AI itself is different from Cloudflare AI Gateway routing.
- OpenRouter public documentation reports a daily free-model counter on an authenticated key endpoint; no actual key/account/remaining checked. API availability ≠ lawful eligibility. No inference requests, probes, signups, overage, payment or account reads were authorized/performed.
- **Hard stop first:** (G1) provider+upstream regional legality for user; (G2) real recurring API grant, cap, reset, provider-enforced strict zero spend/no auto top-up or debt; (G3) privacy/secrets/local loopback auth; (G4) Persian/coding/Tool Calling quality/protocol; (G5) native Windows measured resident RAM, crash/reboot/atomic quota. **No complete candidate passes all**; publish no arbitrary winner score.
- A 429 minute throttle must not masquerade as exhausted daily quota. A 402 paid-credits error, 401 key issue, 403 region restriction, stream disconnect/unknown usage and all-options-expired must fail closed. Model retry must never replay CAP-006/file/PowerShell/Gmail side effects; local trusted executor and explicit user approval remain separate.
